# 설계 메모

## 장르 / 레퍼런스
- 할로우 나이트: 묵직한 타격감 → 가론 (히트스톱, 화면 흔들림, 전진 베기)
- 셀레스테: 정밀한 이동 → 코요테 타임, 점프 버퍼, 가변 점프, 꼭대기 체공
- 데드셀: 빠른 액션 → 유나 대시 + 잔상
- 블래스포머스: 다크 판타지 톤 → ruins 테마 (붉은 달, 성탑 실루엣)

## 카메라
- 사이드뷰 고정, 내부 해상도 480×272 (16px 타일 30×17), 정수 배율 확대
- 방 경계 안에서만 따라감 (방이 화면보다 작으면 중앙 고정), 진행 방향으로 살짝 앞을 봄
- 배경: 하늘(고정) + 원경 0.1 + 중경 0.28 + 근경 0.55 패럴랙스

## 개발 순서 (이 프로토타입이 끝낸 단계)
1. ✅ 이동 조작감: 가속/감속, 코요테 0.1s, 버퍼 0.12s, 점프 컷, 꼭대기 중력 감소
2. ✅ 능력 기반 게이트: 해킹=문, 강공격=벽, 비행·소형=통로/가시밭, 스캔=비밀
3. ✅ 그리드 맵: 문자 그리드, 월드 좌표에 방을 붙이면 자동 연결
4. ✅ 필드 전환: 위치·속도 유지, 좁은 곳에서는 큰 캐릭터로 전환 불가, 공중 콤보 가능
   (유나 더블 점프 → Z-09 호버 등. 호버 연료는 땅에서만 충전되어 무한 비행 불가)

## 캐릭터 전환 규칙
- 발 위치 기준으로 히트박스 교체 → 벽에 끼면 전환 거부
- 점프 횟수 · 공중 대시 · 호버 연료는 "이번 체공" 단위로 공유
- 체력은 파티 공유 (5칸)

## 남은 결정 사항
- 사망 패널티 (현재: 마지막 저장 지점, 수집 상태 유지)
- 적 리스폰 (현재: 방에 들어올 때마다)
